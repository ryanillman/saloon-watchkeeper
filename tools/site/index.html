Saloon Watchkeeper

Install the firmware on a Waveshare ESP32-S3 touch display from this page.

Pre-release software. Not fit for use on a boat. Do not rely on it for navigation or to protect your engine, batteries or boat.

Before you start

  • Use desktop Chrome or Edge (Web Serial). Firefox and Safari cannot flash.
  • Plug the board into this computer with a data USB cable. On the 7" boards use the USB port that shows up as a serial device; if the NMEA 2000 bus is enabled there, use the UART port.
  • Pick your board. The wrong image gives a garbled or dark panel; flashing the right one fixes it.
  • Settings are on the SD card, so an update keeps them. A board with no SD card starts from the defaults.
