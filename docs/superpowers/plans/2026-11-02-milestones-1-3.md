# boat-instruments Milestones 1–3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a simulator with a navigable page shell (M1), bring up all three boards to that shell (M2), and show the Engine role live from Signal K with fault flags (M3).

**Architecture:** Each component under `components/` builds two ways. Under ESP-IDF, its `CMakeLists.txt` calls `idf_component_register`. Under the plain-CMake simulator, it calls `add_library`. The switch is `if(ESP_PLATFORM)`. Pure logic (navigation state, data model, parsers, config, tick math) is plain C with host unit tests. LVGL code is thin, and the simulator renders it to an SDL window or headless to PNG.

**Tech Stack:** C11, ESP-IDF v5.5.1, LVGL v9.3.0, cJSON v1.7.18, Unity v2.6.0 (host tests), SDL2 and libpng (simulator), libcurl ≥ 8.11 with WebSocket support (simulator Signal K transport).

**Spec:** `docs/specs/2026-11-02-boat-instruments-design.md`. Hardware facts: `docs/hardware/boards.md`.

## Global Constraints

- MIT license. No code copied from other firmware projects.
- `components/roles` and `components/ui` must not include any ESP-IDF header. CI enforces this with a grep (Task 4).
- Sources write to `boatdata` and `alerts`. Roles and UI only read.
- Data in `boatdata` is in SI units. Conversion happens only at display.
- A missing value is never stored or drawn as 0. Missing means a fault flag: hidden pointer, red cross, yellow `<FIELD> FAIL`.
- A field that is quiet on a live connection stays valid.
- One UI task owns all LVGL calls.
- Board profiles: `square4` 480×480 (square), `lcd7` 800×480 (wide), `lcd7b` 1024×600 (wide). Simulator boards: `sim480`, `sim800`, `sim1024`, with the same sizes and classes.
- Signal K test server: `http://localhost:3000`, Signal K 2.35.1.
- Commit messages: imperative summary line, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Swiping past the last role or page.** Roles wrap around (last → first). Pages wrap within a role. Task 2 tests both.
2. **A Signal K server restart mid-session.** The client reconnects, resubscribes, and fields flag during the gap and clear on the first new delta. Task 12 tests the state machine; Task 16 checks it live.
3. **A config file with a typo in a role name** (`"engnie"`). The loader reports the key path (`roles[0].role`) and skips that entry. The other roles still load. Task 10 tests this.
4. **A boat where discovery finds zero engines.** Engine shows one instance labelled `ENGINE` with every field flagged, not an empty page. Task 13 tests this.
5. **A value outside the gauge range** (RPM above max). The pointer pins at the end of the scale, and the readout shows the true value. Task 14 tests this.
